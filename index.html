Undergraduate Researcher

UC Santa Cruz jLab (Josephson Lab), ENTS Project

  • Own field reliability for a deployed solar powered sensing node at the UCSC farm, where the dominant failure mode is a unit that reports healthy while sending silently corrupt data.
  • Reproduce those failures on a bench replica so the live node stays in service, then isolate root cause across hardware, firmware, and backend rather than guessing at the pipeline as a whole.
  • Decode nanopb Protocol Buffer telemetry to verify packets survive transport intact, pinning each failure to a specific stage.
  • Build a repeatable validation procedure so any lab member can certify a node end to end, replacing ad hoc spot checks that let bad readings reach production dashboards.

Approach

The interesting failures live at boundaries.

Most of what I enjoy sits where one layer hands off to the next: where a sensor reading becomes a packet, where C becomes a scheduling decision, where Verilog becomes a tile on a die. That is also where the failures hide, which is usually what pulls me in.

Right now that means field reliability for solar powered soil sensing nodes at the UC Santa Cruz farm, a compute cluster for research workloads, and a 2x2 matrix solver I taped out on SKY130. Before that it was kernel threading in Pintos, a VGA game with no framebuffer, and a competition robot that only started working the week it had to.

Away from a terminal: cricket, table tennis, beach volleyball, and cooking for more people than I planned for.
