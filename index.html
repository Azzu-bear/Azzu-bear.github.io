Most of what I enjoy sits at a boundary: where a sensor reading becomes a packet, where C becomes a scheduling decision, where Verilog becomes a tile on a die. The interesting failures live there too, which is usually what pulls me in.

Right now that means field reliability for solar powered soil sensing nodes at the UC Santa Cruz farm, a compute cluster for research workloads, and a 2x2 matrix solver I taped out on SKY130. Before that it was kernel threading in Pintos, a VGA game with no framebuffer, and a competition robot that only started working the week it had to.

Away from a terminal: cricket, table tennis, beach volleyball, and cooking for more people than I planned for.

ls projects/

Matrix Inversion ASIC

verilog · cocotb · openlane · sky130

A 2x2 linear system solver (Ax=b, Q4.4 fixed point) taped out through TinyTapeout. One shared multiplier and a 12 state FSM fit into a 1x1 tile at 50 MHz. Verified in cocotb at RTL and gate level, then hardened to GDS with OpenLane.

silicon

Pintos Kernel Scheduler

c · os internals · thread scheduling

Replaced busy waiting in the Pintos kernel with an ordered sleep list and timed wakeups driven from the 8254 timer ISR. Interrupts disabled around insertion so the list is never edited out from under the handler. All six alarm tests pass under QEMU.

kernel

Sluggers of the Lost Goal

embedded c · esp-idf · uart · hsm

Autonomous ball shooting robot, five weeks and a $200 budget. A PIC32 runs the hierarchical state machines; an ESP32-C3 fans eight VL53L1X time of flight sensors out behind an I2C mux. It shipped with a fixed flywheel speed instead of live ranging, because one bad return in the seconds before a shot cost more than the adaptivity was worth.

robotics

FPGA VGA Arcade Game

verilog · vivado · basys3

A three lane endless runner drawn live to a VGA monitor. No framebuffer: a Basys3 cannot hold a 640x480 frame and there is no time to read one at 40 ns per pixel, so every object answers "is this pixel inside me?" combinationally from the beam position.

fpga

ENTS-tock

tock os · i2c · protobuf

Lab firmware I contribute to. Routed STM32 microlog output over I2C to an ESP32 so it lands on a microSD card, which meant extending the protobuf schema without growing the RAM footprint.

I2C sensor bring up, BLE HID, and RTOS tasks. The lab work that made most of the rest of this page possible, kept around because bring up notes are worth more later than they look at the time.

Thread-Safe Binary Search Tree

c · pthreads · valgrind

A concurrent BST using fine grained mutex locking to support insert, search, and delete across many threads. Hardened against races and leaks with Valgrind under sustained contention until the runs came back clean.

Multi-Client TCP Chat Server

A chat server built on select() based I/O multiplexing, serving many clients concurrently on a single thread and handling connects, disconnects, broadcast, and clean session teardown without disrupting anyone else on the server.
